# Simulación local con VS Code + PlatformIO + Wokwi

1. Instale Visual Studio Code.
2. Instale **PlatformIO IDE** y **Wokwi Simulator**.
3. Abra esta carpeta como proyecto.
4. Compile con **PlatformIO: Build**.
5. Ejecute **Wokwi: Start Simulator**.

Archivos principales:
- `platformio.ini`: placa, framework y bibliotecas.
- `wokwi.toml`: firmware/ELF para la extensión.
- `diagram.json`: componentes y cableado.
- `src/main.cpp`: firmware integrado.

Enlace oficial: https://docs.wokwi.com/vscode/getting-started
